## 4. How feedback is displayed

**GuardSpectrum** (Show screen; the Setup band uses the same control)
- **Axes:** log scale 20 Hz–20 kHz in 100 bands. Labelled ticks only at 100, 1k, 3k, 6k and 12k. No dB labels. GuardSpectrum.cs:25, 60-61, 116-121, 453-457
- **Source data:** /fk/spectrum sends 256 bins, max-pooled from a 2048-point FFT (about 93.75 Hz per bin), taken before the notches. EngineMain.cpp:413-436; FeedbackDetector.h:295-297; AudioEngine.h:341
- **Resampling:** the app takes one nearest bin per log band. Above about 1.3 kHz a band is wider than a bin, so most bins there are never drawn (derived from these lines). ShowView.cs:387-397; SetupView.cs:604-614
- **Traces:** a faint line shows the input (loudest armed slot per band). The filled trace is the input minus a notch response the app computes; it is not a measurement. GuardSpectrum.cs:123-142, 158-187
- **EQ curve:** a pink curve hangs from the top showing the summed cut of all active filters (30 dB full scale). GuardSpectrum.cs:243-285
- **Notches:** short baseline ticks 6–14 px long. Text labels "{f}k · {depth} dB" appear only for the 4 deepest. GuardSpectrum.cs:299-334
- **Detections:** an expanding ring at mid-height that fades over 2.2 s, with no text. GuardSpectrum.cs:402-415
- **Q mismatch:** the computed curve assumes Q 25 × max(1, |cut|/18). The engine uses base Q 12 plus a per-ring Q of f/width, and the notch telemetry carries no Q. NotchResponse.cs:20-27; AudioEngine.h:284; NotchBank.h:124, 834-838; FkEngineClient.cs:233
- **Channel mixing:** every channel's notches are subtracted from the all-channel composite. ShowView.cs:231-233
- **Setup spectrum:** it never receives notches or catches. SetupView.cs:588-626
- **Stale data:** when a channel is disarmed, its last trace and notches stay drawn until the window is reopened. `SetSlot(null)` and `ClearSlots` are never called. GuardSpectrum.cs:89-96; ShowView.cs:232-237
- **Guard Off with Capture off:** the detector is not fed, so /fk/spectrum keeps resending the last frame. The trace and meters freeze. AudioEngine.h:302-330; FeedbackDetector.h:406-409

**Can a user see where feedback is?** Partly.
- The exact frequency of the latest detection is printed in LAST CATCH. ShowView.cs:247
- Exact notch frequencies appear for the 4 deepest only, or in full in Setup's "Filters in place". SetupView.cs:538-575
- A detection's position shows only as an unlabelled ring for 2.2 s.
- A narrow high-frequency ring can be missing from the trace because of the point sampling above.

**SpectrumView (RTA overlay)**
- dB grid at −20/−40/−60/−80 and Hz grid at 100/1k/10k. SpectrumView.cs:118-129
- Notches are full-height dashed lines: amber if locked, otherwise blue-to-red by how much the ring is moving ("heat"). SpectrumView.cs:161-177
- Detection dots fade over 2.5 s. Red means the X32 RTA corroborates it (within 6 %, at least −50 dB, a local peak); amber means it does not. SpectrumView.cs:145-158; Correlator.cs:23-67
- Track spans are shaded, but tracks are sent for slots 0–1 only. SpectrumView.cs:182-193; EngineMain.cpp:476
- No numeric labels.
